# Help with Authwave

Whether you are adding Authwave to your first application or setting up your own provider, these guides will help you find your feet. We've picked out a few useful articles below to walk you through common setup tasks.

## Questions, bugs and suggestions

The [Authwave provider repository](https://github.com/Authwave/provider) is a good place to explore the code and see what we are working on. If you have a technical question or have spotted a bug, please [raise an issue](https://github.com/Authwave/provider/issues). Tell us what you are trying to do and what happened, leaving out passwords, tokens and other private information.

## Reporting a security concern

If you think you have found a security vulnerability, please follow the repository's [security policy](https://github.com/Authwave/provider?tab=security-ov-file) to report it privately. Please do not include security vulnerabilities in a public issue.
