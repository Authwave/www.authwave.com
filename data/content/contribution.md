# Make your first open source contribution

Authwave offers free, one-to-one support to help you make your first open source contribution to an Authwave or PHP.GT repository. Bring an idea, a question or simply a willingness to have a go. We will help you find a starting point and work through the next steps together.

## Who is this for?

This offer is for anyone who has never contributed to open source before and would like to contribute to one of our [Authwave](https://github.com/Authwave/) or [PHP.GT](https://github.com/PhpGt/) projects.

You might be learning to code, working on your own applications or writing software professionally. Making a first contribution can feel unfamiliar at any stage. We are happy to help you get started.

## Small changes count

A contribution can be anything useful to the project. You could:

- Correct a typo or make an explanation clearer.
- Fix a bug you have noticed while using the software.
- Add an example that helps someone understand how something works.
- Implement an idea you would like to see in the project.

There is no need to arrive with a big feature in mind. A small, thoughtful change is a good place to begin.

## We will work through it together

We enjoy writing software and sharing what we have learnt. Our one-to-one support is free, and gives you someone to ask when a step is unclear.

We can help you choose a manageable change, get the project running, understand the relevant code and prepare a pull request on GitHub. We can also work through review feedback with you, so you understand how a proposed change becomes part of a shared project.

If you already have something in mind, tell us about it. If you are not sure where to begin, we can look for a suitable first contribution together.

## Get in touch

Email [contact@authwave.com](mailto:contact@authwave.com?subject=My%20first%20open%20source%20contribution) and let us know that you would like help with your first open source contribution.

Tell us which project interests you and whether you have a change in mind. It is fine if you have not chosen either yet. We will arrange one-to-one support and help you take that first step.
